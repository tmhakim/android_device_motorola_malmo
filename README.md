# LinageOS for Motorola G85 (codename malmo)
This project is a custom LineageOS build for the Motorola G85 (codename malmo), since an official one does not exist. This project needs as much help as it can get to get finished quicker, because the code isn't even ready to be compiled yet....
# How to contribute
**You can help us by forking this repo and finishing things or adding changes to refine it, then submit a pull request. In whatever way you can, please do help.**
